# Mockup source

Source of the design canvas at https://claude.ai/artifact/4MF23wdHWZykkbZL7aivSY
(two phone screens: main screen, picture chooser). The artifact is the live
copy; these files are a snapshot for version control.

Images are uploaded assets referenced as `/_blob/<id>` (the `BLOB` map in
`Main.dc.html`). They live in the artifact, not here; regenerate the renders
with `picmaze.py` if needed. To edit, read the artifact first (it may have been
changed in the canvas editor since this snapshot), then publish to the same URL.
